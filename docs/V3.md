# Sonder v3 — you play too, with other people, anywhere, and you can go back in time

Order agreed 2026-10-15: time travel → play-along → app → rooms → detection → DJ/narrator → DAW.
Checked when implemented, tested and deployed.

## 1. Time travel — record the data, not the audio
- [x] **Data log**: `--record-data <path>` writes every ingested sample (all sources) as a
      compact `.sonder` log (JSONL, gzip optional; header with scene name, seed, wall-clock
      epoch); `sonder record` logs data alongside audio.
- [x] **Replay source**: `kind = "replay.log"` (path or bytes) re-emits a log's samples
      under their original source names with original timing (`speed`, `from`, `to`,
      `loop`); any scene can be fed from any log; `sonder replay <log> [--scene]`.
- [x] **Scrub**: `UserCommand::Seek { to }` and `EngineSnapshot.replay` (position/length/
      speed); a timeline in the web UI and TUI; browser can open a log by drag-and-drop
      (wasm reads the bytes).
- [x] **Daily record** captures the data log and publishes it next to the audio.

## 2. You're in the ensemble — play along
- [x] **`Role::Human`**: a generator that plays `note`/`note_off` events from a human
      input source, snapping pitch to the conductor's harmony (`snap = chord|scale|none`),
      velocity → energy; sustains until note_off; feeds mood like any layer.
- [x] **`human.midi`** (native, midir input) and **`human.keyboard`** (browser: computer
      keys as a two-octave piano, plus Web MIDI inputs) sources emitting `note{key,
      velocity}` / `note_off{key}` and readings `activity`, `register`.
- [x] **Duet mode**: a `jam` scene (`night-freeway` + a human layer on `string.nylon`).
- [ ] **Body as instrument** (v3.1): webcam pose/hand tracking → gestures.

## 3. Together — shared rooms
- [ ] **Relay**: `sonder relay` — a small axum WebSocket pub/sub (rooms by id; host publishes
      scene+seed+epoch, live samples, captions; guests subscribe; presence + chat), Dockerfile,
      docs for a $5 VPS / Fly.io; a Cloudflare Worker port is a stretch goal.
- [ ] **Host**: `sonder play --room <wss://relay/r/<id>>` publishes; `--room-name`.
- [ ] **Guest**: the site joins with `?room=<url>` (worker mode: same scene + seed, fed by the
      host's samples through the replay path, clock offset estimated), or any browser opens
      the host's own URL (ws mode already is a room). Listener count and chat in the UI;
      chat lines pin to engine time and show as captions.
- [ ] **Moments**: "save this moment" writes the last N minutes of the room's data log.

## 4. A real app
- [x] **Desktop (Tauri)**: the web UI around the native engine with native audio, MIDI in/
      out, local sources; CI builds for Linux/macOS/Windows (`.github/workflows/desktop.yml`).
- [x] **PWA**: manifest, service worker (offline shell + wasm), install prompt, media
      session (lock-screen controls), battery-aware tick rate when hidden.

## 5. Eyes (v3.1)
- [x] Small ONNX detector (tract-onnx, YOLO11n) for cameras: vehicle classes, people, birds.

## 6. Scene intelligence
- [ ] **DJ**: rule-based scene switching on world events (`dj.toml`: conditions over any
      source's readings/events across scenes — e.g. quake ≥ M5 → `seismic` for 10 min,
      lightning rate high → `storm`), with hold times, a visible reason, `SetDj` on/off and a
      `dj` panel; `sonder play --dj`.
- [ ] **Narrator**: optional LLM prose captions every N minutes from the recent captions/
      events (Claude API, key from env / browser localStorage), shown as captions; unit-tested
      with canned responses.

## 7. For musicians
- [ ] **OSC out** (`--osc host:port`): notes, drums, layer params, signals, harmony, form.
- [ ] **Ableton Link** (`--link`): tempo/beat phase shared with Link peers (rusty_link).
- [ ] **Stems**: `sonder record --stems` renders one WAV per layer (deterministic solo renders).
- [ ] CLAP plugin — deferred to v3.2.
- [ ] **Body as instrument** (webcam motion zones → gestures via the existing tracker; `body` scene).
