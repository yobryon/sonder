# Sonder in the browser (wasm)

The whole pipeline — features → composer → synth — is pure Rust with no I/O, so it runs
unchanged in a Web Worker compiled to WebAssembly. What changes in the browser:

| Native | Browser |
|---|---|
| sources are tokio tasks (`sonder-sources`) | **JS adapters** (`fetch`, `EventSource`, `WebSocket`, webcam, mouse) push samples into the engine; the synthetic sims (`synthetic.freeway`, `synthetic.walk`, `clock.astro`) are stepped inside Rust |
| cpal / WAV / PCM | the Worker renders 20 ms blocks → main thread → the existing AudioWorklet (`worklet.js`) |
| `/ws` snapshots, `/audio` PCM over WebSocket | the Worker posts snapshot JSON and PCM chunks; `app.js` gets a *transport* abstraction (`ws` or `worker`) |
| `camera.mjpeg` | **webcam** (`getUserMedia`) → gray frames → the pure-Rust tracker via `push_frame` |
| `system.metrics` | `browser.input` (mouse speed, clicks, scroll, keys, tab visibility) |

Deployed as a static site (`site/`) — GitHub Pages friendly, no server.

## Crate `sonder-wasm` (cdylib, wasm-bindgen, `--target web`)

```ts
// pkg/sonder_wasm.js (generated by wasm-bindgen)
export default function init(input?): Promise<void>;

export function builtin_scenes(): Array<{ name: string; title: string; description: string; tags: string[]; toml: string }>;
export function validate_scene(toml: string): string[];            // [] when valid
export function version(): string;

export class Engine {
  constructor(scene_toml: string, seed: bigint, sample_rate: number);   // throws on invalid scene
  free(): void;

  // Which sources the scene needs. `builtin: true` means Rust steps it itself
  // (synthetic.*, clock.astro); everything else must be fed by a JS adapter via push_sample.
  source_specs(): Array<{ name: string; kind: string; params: Record<string, unknown>; builtin: boolean }>;

  // Feed a sample from a JS adapter. `json` is one of:
  //   {"type":"reading","values":{"count":14,"mean_speed":0.6}}
  //   {"type":"event","name":"quake","intensity":0.4,"attrs":{"mag":4.1,"place":"..."}}
  //   {"type":"status","state":"connecting|live|idle|reconnecting|failed","message":"..."}
  //   {"type":"viz","payload":{...}}
  // Samples are stamped with the engine's current time.
  push_sample(source: string, json: string): void;                     // throws on bad JSON

  // Webcam path: an 8-bit grayscale frame for a camera source (kind camera.* in the scene).
  // Runs the tracker and emits blob/crossing events, readings and viz like the native source.
  push_frame(source: string, gray: Uint8Array, width: number, height: number): void;

  // Advance the engine by one control tick (20 ms): steps builtin sims, runs features and the
  // composer, renders audio. `out` must have length 2 * frames_per_tick() (interleaved stereo f32).
  tick(out: Float32Array): void;
  frames_per_tick(): number;        // sample_rate / 50
  time(): number;                   // engine seconds so far

  snapshot_json(): string;          // latest EngineSnapshot (same JSON the native /ws sends)
  command(json: string): void;      // a UserCommand, e.g. {"cmd":"toggle_mute","layer":0}
}
```

Timing model: the Worker owns the clock. It keeps the engine ~250 ms ahead of wall time
(`engine.time() - elapsed < 0.25 → tick()`), posts each rendered block to the main thread as
a transferable `Float32Array`, and the main thread forwards it to the worklet exactly as it
forwards WebSocket PCM today. Snapshots are posted every other tick (25 Hz).

## Browser source adapters (JS, in the Worker)

One module per kind under `crates/sonder-web/static/sources/`, each `export default
class { constructor(spec, emit) ; start() ; stop() }` where `emit(sampleJson)` calls
`engine.push_sample(spec.name, json)`. Kinds: `usgs.earthquakes`, `open-meteo.weather`,
`wikipedia.recent-changes` (EventSource), `coinbase.trades` (WebSocket), `opensky.flights`,
`noaa.space-weather`, `noaa.tides`, `hackernews.firehose`, `github.events`, `iss.position`
(uses `https://api.wheretheiss.at/v1/satellites/25544` — open-notify is http-only),
`http-json`, `sse`, `websocket`, `browser.input`, `camera.webcam` (also used for `camera.mjpeg`).
Unavailable kinds (`system.metrics`, `file-tail`, `stdin`) report `status: failed` with a
message and the layer simply plays on the conductor alone.

## Build

```
scripts/build-site.sh      # cargo build --release --target wasm32-unknown-unknown -p sonder-wasm
                           # wasm-bindgen --target web --out-dir site/pkg
                           # copies crates/sonder-web/static/* into site/
```
`.github/workflows/pages.yml` runs the same and deploys `site/` to GitHub Pages.
